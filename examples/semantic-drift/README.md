# Semantic drift demos

Four runnable demos that show each drift in the semantic layer, run against the frozen
"before" code (`before/`) and the current "after" code.

```bash
make semantic-drift-demo
```

Requires `pyshacl` (in `requirements.txt`). Full write-up:
[Semantic drift: before and after](../../docs/case-study/fintech-semantic-integration/semantic-drift.md).
